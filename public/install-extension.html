⚡ Cash Management BC - Chrome Extension

CSC AEPS, Digipay, SBI Kiosk Receipt Auto-Capture & Live Sync

🚀 Easy Step-by-Step Installation
● EXTENSION READY
  • 1
    Google Chrome ya koi bhi Chromium browser (Edge, Brave) me naya tab kholein aur URL me dalein:
    chrome://extensions
  • 2
    Top-Right corner me Developer mode ka toggle ON karein.
  • 3
    Top-Left corner me Load unpacked button par click karein aur ye folder select karein:
    extension/ (Project folder ke andar)
  • 4
    Ya agar aap ZIP file chahein to ek click me ZIP download karke extract kar sakte hain:
    ⬇️ Download Extension (.zip)
⌨️ Keyboard Shortcuts & Usage
Alt + C (Tarika B)
Banking portal par receipt khuli hone par Alt + C dabate hi receipt auto-capture ho kar Cash Management project tab me #bcModal ya #cscNewAppModal khol kar saara data bhar degi.
Alt + Shift + C (Tarika C)
Portal ke upar hi Floating Modal khul jayega jahan se aap Direct Database Save kar sakte hain ya text paste karke Re-Parse kar sakte hain.
